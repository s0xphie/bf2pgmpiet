# squarier pgmpiet from brainfuck programs
bf2pgmpiet.py -- folded (squarish) Brainfuck -> pgmpiet compiler

Usage:
```
python3 bf2pgmpiet.py program.bf [tape_size]
```
```
python3 bf2pgmpiet.py "++[>+++<-]>." [tape_size]
```
