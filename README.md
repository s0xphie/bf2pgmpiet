# squarier pgmpiet from brainfuck programs
bf2pgmpiet.py -- folded (squarish) Brainfuck -> pgmpiet compiler

Usage:
```
python3 fbf_compiler.py program.bf [tape_size]   # -> fbf_out.pgm  (P5)
```
```
python3 fbf_compiler.py "++[>+++<-]>." [tape_size]
```
